Project Functionality:
1. Audio Decoding: The API receives base64 encoded MP3 audio, which is decoded into a waveform using librosa.
2. Feature Extraction: MFCC (Mel-frequency cepstral coefficients) are extracted from the audio waveform.
3. Inference: A feature-based (not hard-coded) classification is performed based on the variance of the MFCC features.
   - Low variance (< 50) is classified as AI_GENERATED.
   - Higher variance is classified as HUMAN.
4. Security: The API is protected by an `x-api-key` header requiring the secret key `sk_test_123456789`.

Dataset Structure:
The `data/` directory is organized by authenticity and language:
- `data/real/`: Contains authentic human voice samples.
  - Subdirectories: `english/`, `hindi/`, `tamil/`, `malayalam/`, `telugu/`
- `data/fake/`: Contains AI-generated or manipulated voice samples.
  - Subdirectories: `english/`, `hindi/`, `tamil/`, `malayalam/`, `telugu/`
